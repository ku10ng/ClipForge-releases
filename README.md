# ClipForge — bản phát hành

Repo này chỉ chứa bản build của ClipForge để app tự cập nhật (mã nguồn ở repo riêng).
Cài lần đầu: tải mọi file `files-<phiên bản>-*.zip` của bản phát hành đầu tiên và giải nén chung
vào một thư mục (nên dùng `%LocalAppData%\Programs\ClipForge`). Các bản sau app tự cập nhật.
