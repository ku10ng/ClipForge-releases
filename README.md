# ClipForge — bản phát hành

Repo này chỉ chứa bộ cài ClipForge (mã nguồn ở repo riêng).

Bản mới nhất: **0.2.2**.

**Cài lần đầu:** tải [ClipForge-Setup.exe](https://github.com/ku10ng/ClipForge-releases/releases/download/v0.2.1/ClipForge-Setup.exe), chạy và bấm Next → Install. Nếu Windows cảnh báo: More info → Run anyway. Mở app lần đầu, app tự hỏi cập nhật lên bản mới nhất (nếu có). Đã cài rồi thì app tự cập nhật.
